# online-electronics-store

проект команды из 4 человек: бэкенд(матвей), фронтенд(plyoo), тестировщик(ваня), дизайнер(егорик).

## Ветки

- `main` — для рискованных(опасно работать).
- `develop` — что-то новое сюда и потом в мейн(безопасно).

## Как мы работаем

1. Задача → создаём ветку `feature/название-задачи` от `develop`.
2. Делаем изменения, коммитим.
3. Открываем Pull Request в `develop`.
4. Тестировщик(я(ваня)) проверяет код в `develop`.
5. Когда всё работает → Pull Request `develop → main` → победа.

## Правила

- В `main` напрямую не пушим(желательно) — только через Pull Request.
- Названия веток под задачу(по возможности), а не под человека(под человека тож можно).
- Описание PR: что сделано и как проверить(необязательно).
